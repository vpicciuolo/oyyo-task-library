# Blueprint

## Goal

Create a complete project or creative blueprint.

## Expected deliverable

Source facts, objective, audience, requirements, detailed structure, specialist work packages, production prompts, owners, timeline, acceptance criteria and next actions.

## Useful brief inputs

- Goal
- Audience
- Context
- Constraints

## Example request

> Help me create a complete project or creative blueprint for my business. The audience is [audience]. Use [facts] and deliver [format].

## Working boundaries

The template structures the requested work. It does not itself grant tool access or prove that execution, publishing, browsing, generation or exports have occurred. The actual selected team, qualified model and available tools determine the result. Important factual claims and specialist outputs need appropriate review.
