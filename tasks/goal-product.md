# Product roadmap

## Goal

Build a product roadmap.

## Expected deliverable

User problems, priorities, requirements, acceptance criteria and phased delivery.

## Useful brief inputs

- Goal
- Audience
- Context
- Constraints

## Example request

> Help me build a product roadmap for my business. The audience is [audience]. Use [facts] and deliver [format].

## Working boundaries

The template structures the requested work. It does not itself grant tool access or prove that execution, publishing, browsing, generation or exports have occurred. The actual selected team, qualified model and available tools determine the result. Important factual claims and specialist outputs need appropriate review.
